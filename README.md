# 🌱 Protocolo Éden

### Estufa Inteligente Adaptável para Marte
**Global Solution 2026 — Computational Thinking with Python**

---

## 📖 Sobre o Projeto

O **Protocolo Éden** é uma solução desenvolvida em Python com o objetivo de simular um sistema inteligente de gerenciamento agrícola para Marte.

O projeto busca solucionar os desafios da produção de alimentos em ambientes extraterrestres por meio de estufas adaptáveis, capazes de armazenar informações sobre diferentes culturas, monitorar condições ambientais e auxiliar no controle do cultivo.

A proposta foi desenvolvida aplicando os conceitos estudados na disciplina **Computational Thinking with Python**, utilizando funções, listas, estruturas de decisão e repetição para criar um sistema funcional executado via terminal.

---

## 🎯 Objetivos

- Simular a agricultura em Marte através de estufas inteligentes;
- Gerenciar diferentes culturas e suas condições ideais;
- Controlar o estoque de sementes disponível para plantio;
- Monitorar temperatura e umidade das estufas;
- Exibir previsões de colheita das culturas cadastradas;
- Aplicar conceitos de programação em Python na resolução de problemas.

---

## 🖥️ Funcionalidades

### 🌿 Gerenciamento de Estufas
Permite cadastrar novas culturas e visualizar informações das estufas já existentes, incluindo temperatura ideal, umidade ideal e previsão de colheita.

### 🌱 Almoxarifado de Sementes
Responsável pelo controle do estoque de sementes. O usuário pode consultar quantidades disponíveis, adicionar novas sementes e utilizar sementes para cultivo.

### 🤖 Monitoramento Automático
Simula o monitoramento inteligente das estufas. O sistema compara os valores informados pelo usuário com os parâmetros ideais da cultura selecionada e indica ações como:

- Aquecimento do ambiente;
- Refrigeração do ambiente;
- Irrigação do solo;
- Redução da irrigação;
- Ambiente ideal para cultivo.

### 📅 Previsão de Colheita
Cada cultura cadastrada possui uma previsão de colheita, permitindo acompanhar o desenvolvimento esperado da plantação.

### 📊 Histórico de Utilização
Registra as funções acessadas durante a execução do sistema e apresenta um histórico de navegação do usuário.
