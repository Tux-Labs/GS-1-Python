📖 Descrição do Projeto

O Protocolo Éden é um projeto acadêmico desenvolvido em Python com o objetivo de criar uma solução computacional para auxiliar a agricultura em Marte. O sistema simula uma rede de estufas inteligentes capazes de armazenar informações sobre diferentes culturas e suas condições ideais de desenvolvimento.

A proposta busca demonstrar como a programação pode ser utilizada para resolver problemas relacionados à produção de alimentos em ambientes extremos, utilizando conceitos de organização, monitoramento e automação.

🎯 Objetivo da Solução

O objetivo do projeto é aplicar os conceitos estudados na disciplina de Computational Thinking with Python para desenvolver uma solução funcional voltada à agricultura extraterrestre.

A solução busca:

Gerenciar estufas e culturas cadastradas;
Registrar condições ideais de cultivo;
Controlar o estoque de sementes;
Simular monitoramento ambiental automatizado;
Exibir previsões de colheita;
Registrar o histórico de utilização do sistema.
🧠 Conceitos de Python Utilizados

Durante o desenvolvimento do projeto foram aplicados os seguintes conceitos:

Estruturas de decisão (if, elif e else);
Estruturas de repetição (while e for);
Manipulação de listas;
Manipulação de strings;
Criação de funções com def;
Passagem de parâmetros;
Entrada de dados com input;
Saída de dados com print.
🖥️ Funcionalidades do Sistema
1. Solução

Apresenta uma breve descrição da proposta do Protocolo Éden, explicando o problema abordado e a solução desenvolvida.

2. Estufas

Permite visualizar as estufas cadastradas, consultar suas informações e adicionar novas culturas ao sistema, definindo temperatura ideal, umidade ideal e previsão de colheita.

3. Almoxarifado

Responsável pelo gerenciamento das sementes disponíveis para cultivo. O usuário pode visualizar o estoque, adicionar novas sementes e utilizar sementes já cadastradas.

4. Monitoramento Automático

Simula o monitoramento das condições ambientais de uma estufa específica. O sistema compara os valores informados pelo usuário com os parâmetros ideais da cultura e apresenta ações corretivas quando necessário, como:

Aquecimento do ambiente;
Refrigeração do ambiente;
Irrigação do solo;
Redução da irrigação;
Indicação de ambiente ideal.
5. Histórico

Exibe a quantidade de funções acessadas e registra o histórico de navegação do usuário durante a execução do programa.

🌍 Aplicação da Solução

O Protocolo Éden representa uma proposta de sistema para auxiliar a produção de alimentos em ambientes extraterrestres. A solução demonstra como recursos computacionais podem contribuir para a organização, monitoramento e gerenciamento de cultivos em locais onde a agricultura convencional não seria viável.

🚀 Conclusão

O projeto demonstra a aplicação prática dos conceitos de programação em Python por meio da criação de um sistema funcional baseado em menus, listas, funções e estruturas de controle. A solução desenvolvida permite gerenciar estufas, controlar sementes, monitorar condições ambientais e acompanhar previsões de colheita, simulando o funcionamento de uma estufa inteligente para Marte.
